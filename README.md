# 🌌 CyberVision - Advanced Image Processing Studio
An elegant, dark-themed, and futuristic desktop application for comprehensive image processing and computer vision operations. Built with **Python**, **Tkinter**, **OpenCV**, and **NumPy**, this tool provides an intuitive graphical interface (GUI) to apply various digital image processing algorithms instantly.
---
## ✨ Features & Functionalities
The application organizes core image processing techniques into dedicated tabs:
* **⚡ Point Operations:** Pixel-level manipulations including Addition, Subtraction, Division, and Image Complement.
* **🎨 Color Space Operations:** Channel-specific modifications like increasing Red intensity, swapping Red and Green channels, or completely eliminating Red.
* **📊 Histogram Enhancements:** Contrast optimization via Histogram Stretching and Histogram Equalization.
* **📉 Linear Filters:** Spatial domain smoothing using Average Filters and edge highlighting via Laplacian Filters.
* **📐 Non-Linear Filters:** Order-statistic filtering including Maximum, Minimum, Median, and Mode filters.
* **🛡️ Noise & Restoration:** * Simulate **Salt & Pepper** or **Gaussian noise**.
    * Restore images using Average, Median, Outlier Detection, and Image Averaging techniques.
* **🔍 Edge Detection:** Highlight structural boundaries utilizing the Sobel Operator.
* **🧬 Morphological Operations:** Binary/Grayscale shape processing including Dilation, Erosion, and Opening.
* **🖼️ Boundary Extraction:** Isolate structures using Internal Boundary, External Boundary, and Morphological Gradient techniques.
---
## 🛠️ Tech Stack & Libraries
* **UI Framework:** Tkinter (Custom stylized dark-mode theme)
* **Core Processing:** OpenCV (Open Source Computer Vision Library)
* **Mathematical Operations:** NumPy
* **Advanced Filtering:** SciPy (ndimage)
* **Imaging Pipeline:** Pillow (PIL)
